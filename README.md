# Student Portfolio

A beginner-friendly personal portfolio made with only HTML and CSS.

## Edit the site

- Open `index.html` to change the words, links, and project details.
- Open `styles.css` to change colors, spacing, and type sizes.
- Comments in both files label the main sections.

## Preview the site

Double-click `index.html` to open it in a browser. No installation or build step is needed.

## Easy first changes

1. Replace “Alex Morgan” with your name.
2. Replace `hello@example.com` with your email address.
3. Replace the `#` placeholder links with links to your work and social profiles.
4. Change the project titles and descriptions after each course assignment.
